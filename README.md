# DevOps Project 2 — Multi-Server Deployment Lab

This is an earlier hands-on project exploring an application deployment workflow across build, application and QA environments. The original notes were recovered from OneNote and organised into the stages below.

This is a **historical learning project**, not a production-grade CI/CD setup.

## Topics covered

Jenkins, Java/Maven, Tomcat, Docker, Ansible, AWS, GitHub and deployment to multiple servers.

## What I was practising

- Understanding how changes move from a source repository into a deployment workflow
- Separating build, application and test responsibilities
- Using configuration and deployment tools rather than manually repeating every step

## Limitations and lessons

These are my original step-by-step notes, mostly command-driven and written during the build. I haven't revalidated them using current versions. If I rebuild this project, I would add a clear architecture diagram, repeatable scripts, checks for failed deployments and documented resource cleanup.

The original stages remain available for anyone who wants to inspect the work.
